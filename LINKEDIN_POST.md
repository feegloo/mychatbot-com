# LinkedIn Post — ChatRAG Launch

I built **ChatRAG** — an AI-powered document Q&A app.

Upload your files. Ask questions. Get answers grounded in your actual content — with citations pointing to the exact source.

No hallucinations. No guessing. Just your documents, answering back.

🔹 **How it works:**
You drag-and-drop PDFs, Word docs, spreadsheets, or any text file. The system indexes everything using semantic embeddings, then lets you chat with your documents naturally — like talking to the person who wrote them.

🔹 **What makes it different:**
• Every answer includes **citations** — see the exact passage, page, and file
• **Shareable links** — send a conversation URL to your team, they can chat with the same docs
• **Smart suggested questions** — AI generates starter prompts so you know what to ask
• **10+ file formats** — PDF, DOCX, Excel, CSV, JSON, HTML, XML, Markdown, and more
• **Multi-language** — auto-detects document language and responds accordingly
• **Real-time streaming** — answers appear word-by-word as the AI thinks

🔹 **The stack:**
Python · LangChain · ChromaDB · OpenAI · Anthropic · Vue 3 · Node.js · PostgreSQL · Docker · GCP Cloud Run

Try it 👉 https://chatrag.app
